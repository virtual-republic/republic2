# Laws to pass

Seven drafts. Four give effect to provisions the Constitution leaves to statute,
which the Republic currently lacks — those are marked **required**. Three are
ordinary policy, there to be argued about.

Lay one with:

```bash
republic propose --title "<title>" --by c-0001 --class <class> \
  --cites <the provisions it is made under> \
  --text "$(cat samples/laws/<file>.md)"
```

Or paste the text into **Assembly → Lay a measure** on the site, where the
citation helper will insert the provisions for you.
